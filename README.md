# Shorts Studio bySom · 0.5.2

유튜브 링크 또는 로컬 영상을 프리셋에 맞춰 쇼츠로 편집하는 Windows Electron 앱입니다. 원본 장면·원음을 유지하며 제목·자막·크롭·배경음악을 합성합니다. YouTube Finder의 다크 UI를 기준으로 제작했습니다.

## 실행

[GitHub Releases](https://github.com/gustjr1118-ai/Short_Auto/releases)에서 Windows x64용 `.7z` 파일을 받아 전체 압축을 풉니다. 기존 앱을 닫은 뒤 압축을 푼 폴더의 `Shorts Studio bySom.exe`를 실행합니다. 배포본에는 Electron·FFmpeg·FFprobe·yt-dlp·Whisper가 포함되어 기본 편집과 전사를 Node.js·Python 설치 없이 실행할 수 있습니다. 기존 설정·프로젝트는 같은 저장 위치에서 이어서 사용합니다.

소스 폴더에서 만든 배포본은 `Start.cmd`로 실행할 수 있습니다. Windows에서 Node.js 24로 `npm ci`, `npm test`, `npm run dist:release`를 실행하면 `release/0.5.2-optimized/`에 `.7z`와 SHA-256 파일이 만들어집니다. ZIP이 필요한 경우 `npm run dist:zip`을 사용합니다. `main`에 새 `package.json` 버전을 푸시하거나 대응하는 `v` 태그를 푸시하면 GitHub Actions가 Windows 릴리스를 생성합니다.

## 0.5 작업 흐름

- 왼쪽 하단 **작업 현황**에서 현재 단계, 대기 순서, 진행 기록, 결과와 재시도를 확인합니다.
- 오른쪽 상단 **Codex** 버튼으로 계정 잔여량과 이 앱의 최근 30분 토큰 사용량을 봅니다. 한도 기간과 초기화 시각은 계정 조회값을 사용합니다.
- **여러 편 → 하이라이트 추천**은 원본에서 추출한 대표 장면과 확보된 대사를 사용합니다. **이 구간 보기**를 누르면 해당 후보의 원본 시작 지점부터 종료 지점까지 재생합니다. 오른쪽 **편집 대상**에서 활성 쇼츠를 바꾸면 화면·제목, 자막, 소리 탭이 해당 편의 설정을 엽니다.
- **개별 편집**에서 자막 추출·가져오기·번역, 원본 자막 가리기, 화면, 제목을 설정합니다. 저장한 스타일 프리셋을 불러오거나 선택한 편에 Codex 요청을 보낼 수 있습니다. **선택한 N편 제작**을 눌러 확정한 편을 출력합니다.

## 0.4 사용 방법

- **Codex 모델·추론 강도**는 설정의 **AI·음성 전사 → Codex CLI**에서 선택합니다. 모델 이름을 입력하거나 제안 목록에서 선택할 수 있습니다. 빈 모델과 기본 강도는 CLI 기본값을 사용합니다. 높은 강도의 지원 여부는 모델·계정·CLI 버전에 따라 달라집니다.
- **편집 → 여러 편**에서 15·30·45·60초와 수량 1~10편을 선택합니다. Codex가 전사를 바탕으로 구간을 추천합니다. 선택한 구간만 작업할 수 있고, 실패한 편은 개별 재시도할 수 있습니다. 목표 수량보다 적은 후보만 확보되면 확보 건수를 표시합니다.
- **자막** 탭에서 선택 구간의 원문 자막이나 Codex가 다듬은 자막을 반영하고, 확인 후 다시 제작합니다. 완성본은 **결과 → 이 버전 개별 편집**으로 열면 독립 프로젝트에서 수정할 수 있습니다.
- **결과 → 자막 편집**에서 선택한 쇼츠의 SRT를 열어 문구를 직접 고칩니다. 왼쪽 미리보기에서 수정 문구를 보고, 자막 시간을 누르면 해당 위치로 이동합니다. **다른 SRT 열기**로 가져오는 UTF-8 파일은 완성본의 00:00을 기준으로 작성하세요. **영어 → 한국어 번역**은 설정에 저장한 Codex CLI 모델·추론 강도를 사용하며 자막 번호와 시간은 유지합니다. 번역에는 Codex CLI 로그인과 인터넷 연결이 필요합니다.
- **자막 적용해 새 버전 만들기**는 원본 영상에서 기존 구간과 스타일을 재현하고 기존 MP4의 소리를 사용해 새 MP4와 SRT를 만듭니다. 작업에는 원본 영상과 기존 MP4가 필요합니다.
- **화면·제목 / 자막** 탭에서 위치와 정렬을 조정한 뒤 내 프리셋으로 저장합니다. **화면·제목 → 화면 → 원본 자막 가리기**에서는 블러·검정 박스·하단 크롭을 선택합니다. 가림 영역은 원본 프레임에서 확인하고 실제 가림은 완성본에서 확인합니다.
- **로컬 전사**는 0.3.1부터 기본 실행 파일과 다국어 모델이 포함됩니다. 설정에서 **로컬 Whisper CLI**를 선택하면 경로를 비워 두고 바로 쓸 수 있습니다. 직접 지정한 파일을 찾을 수 없으면 내장 도구를 사용합니다. 다른 모델로 바꾸려면 실행 파일과 모델을 지정하세요. 한국어에는 다국어 모델을 사용합니다. 링크 자막 우선 설정을 켜면 yt-dlp로 해당 언어의 자막을 먼저 찾습니다.
- **AI 음성**은 [Qwen3-TTS 설치 가이드](https://github.com/QwenLM/Qwen3-TTS)에 따라 구성한 Python 실행 파일과 로컬 CustomVoice 모델 폴더를 설정합니다. **소리 → 자막 AI 음성**에서 원음 혼합 또는 원음 음소거를 고릅니다. 실제 자막을 읽으며, 낭독이 길면 해당 자막의 문구나 시간을 조정한 후 다시 제작합니다.

## 첫 쇼츠 만들기

1. 첫 화면에서 영상 파일을 가져오거나 유튜브 단일 링크를 입력합니다. 편집 화면 상단에서 **한 편 / 여러 편**과 프리셋을 선택합니다.
2. **원본 전체**로 영상 끝까지 탐색하고, 원하는 장면에서 **현재 재생 위치를 시작으로**를 누르거나 오른쪽 **구간**의 시작·종료를 입력합니다. **선택 구간**으로 바꾸면 쇼츠 미리보기를 확인할 수 있습니다.
3. 상단 **쇼츠 만들기**를 누릅니다. **결과**에서 쇼츠와 버전을 골라 재생하고 MP4 또는 SRT를 저장합니다.
4. 편집을 바꾼 뒤 **새 버전 만들기**를 누르면 같은 쇼츠에 버전이 추가됩니다. 자막만 수정하려면 결과에서 해당 쇼츠의 **자막 편집**을 엽니다.
5. 원하는 스타일을 **프리셋으로 저장**하면 다른 원본에서도 반복 사용할 수 있습니다.

로컬 편집과 출력에는 AI 연결이 필요하지 않습니다. 자동 전사는 로컬 Whisper 또는 선택한 OpenAI 전사 API로 실행합니다. 직접 SRT 자막을 가져오거나 입력할 수도 있습니다. SRT의 시간은 원본 영상 기준입니다.

## 제공하는 기능

- 프리셋 8종: 대화 하이라이트 / 고정 제목 해설 / 원본 보존 / 상황·반전 / 단계별 사용법 / 제품 실사용·비교 / 비포·애프터 / TOP 3 목록.
- 각 프리셋의 예시 자막 한 종류. **자막 → + 예시 자막 추가**로 삽입하고 위치·크기를 테스트합니다.
- 시점별 상황 안내·단계·제품 라벨, 이전/이후·항목 이름 표시, 원본 내 최대 5구간 연결·순서 변경·구간별 화면 조정.
- 프로젝트 자동 저장·검색·복제, 변경 되돌리기, 출력 버전 선택.
- 세로 크롭·전체 맞춤·흐린 배경, 제목·문장 자막·강조어, 원음/BGM 볼륨·페이드.
- 사용자 프리셋 복제·편집·저장·JSON 가져오기/내보내기.
- 기본 한국어 편집 요청 또는 Codex/Claude CLI 연결을 통한 편집 요청.
- 전사문 기반 연속 구간 후보 최대 3개. 기본 규칙 또는 연결한 AI가 추천합니다.
- 단일 제작 큐, 취소·실패·재시도·재실행 시 중단 상태 복구.
- 1080×1920·30fps·H.264/AAC MP4, 별도 SRT 출력.

## 연결

**설정 → AI·음성 전사**에서 엔진을 고릅니다. Codex/Claude는 해당 CLI에서 로그인을 완료해야 합니다. 비어 있는 경로는 자동 탐색하며 실행 파일을 직접 선택할 수도 있습니다. CLI 모델을 비우면 CLI 실행 기본 모델을 사용합니다. 앱은 기존 CLI 사용자 설정·MCP 구성을 불러오지 않는 전용 호출을 사용합니다.

로컬 전사와 로컬 음성 합성은 PC에서 처리합니다. OpenAI 전사 API를 선택하면 분석용 오디오가 전달되고, 외부 텍스트 AI 사용 시 전사·편집 요청이 해당 AI로 전달됩니다. API 키는 OS 보호 저장소로 암호화되며 프로젝트와 프리셋에 저장되지 않습니다.

**설정 → 도구·진단**에서 도구 버전과 경로를 확인할 수 있습니다. 유튜브는 공개 단일 영상부터 지원하며 재생목록·라이브·인증이 필요한 영상은 지원 대상에서 제외합니다. 접근 불가·삭제·네트워크 제한은 오류로 표시하며 로컬 파일로 진행할 수 있습니다.

## 기본 편집 규칙의 요청 예시

- `제목을 “핵심은 바로 이것”으로, 자막은 크게`
- `자막은 노란색으로`
- `화면을 조금 왼쪽으로`
- `원본 전체 화면으로`
- `배경을 흐리게`
- `배경음악은 절반으로`
- `처음 3초는 빼줘`

기본 규칙이 처리하지 못하는 요청은 오류를 표시합니다. 더 자유로운 요청은 CLI 연결을 사용하세요. 요청은 편집 설정에 적용되며 MP4 갱신은 다시 제작해야 합니다.

## 데이터 위치

- 설정·프로젝트 목록·프리셋: `%APPDATA%/Shorts Studio bySom/studio.sqlite`.
- 큰 파일·완성 영상: 기본 문서 폴더의 `Shorts Studio/projects/<프로젝트 ID>/`.
- 로컬 원본은 원래 위치를 참조합니다. 원본을 옮기거나 수정하면 다시 가져와 주세요.
- 각 출력은 고유 폴더에 `final.mp4`, `captions.srt`, `subtitles.ass`, `render-manifest.json`을 보관합니다.
- 개발 테스트는 `SHORTS_STUDIO_DATA` 환경 변수로 별도 설정 폴더를 지정할 수 있습니다.

## 현재 범위

원본 1개, 30분·2GB 이하, 결과는 최대 60초입니다. 연속 구간 또는 같은 원본의 최대 5구간 연결을 지원합니다. 자동 얼굴 추적·여러 파일 합성·생성형 장면·TTS·캡컷/프리미어 프로젝트 출력은 이후 범위입니다. 미리보기는 편집 배치 예시이고 정확한 렌더링 결과는 완성본에서 확인합니다. 자동 음성 인식 결과는 직접 수정할 수 있습니다.

## 예시 자막으로 출력 테스트

1. 원본을 가져오고 프리셋을 선택합니다.
2. 오른쪽 **자막** 탭을 열고 상단의 **+ 예시 자막 추가**를 누릅니다.
3. 선택한 구간의 현재 재생 위치에 최대 3초짜리 예시 자막이 추가되고, 자막 표시가 켜지며 해당 위치로 이동합니다. 재생 위치가 선택 구간 밖이면 첫 구간 시작에 넣습니다.
4. 글자 크기·색·하단 여백을 조정한 뒤 **쇼츠 만들기**를 누르면 실제 MP4에서도 확인할 수 있습니다. 예시도 실제 영상과 SRT에 포함됩니다.
5. 테스트가 끝나면 해당 자막의 ×로 삭제하거나 문구를 고친 뒤 **실제 자막으로 사용**을 누릅니다. 예시 표시가 붙은 자막은 자동 구간 추천에서 제외됩니다. 반복해서 누르면 기존 테스트용 예시 1개를 새 위치로 바꾸며, 실제 대사 자막은 덮어쓰지 않습니다.

예시 문구는 프리셋 보관함의 **복제·편집 → 예시 자막**에서 바꾸고 내 프리셋으로 저장할 수 있습니다. 새 예시를 추가할 때 현재 선택한 프리셋의 문구를 사용합니다.

## 목적별 프리셋 구성

- **상황·반전:** 사건의 맥락과 결과가 있는 구간을 고른 뒤 **구성 → 상황·결과 표시 틀 넣기**에서 문구·시점을 조정합니다.
- **단계별 사용법:** **구성 → 단계 표시 틀 넣기**로 3단계 안내 틀을 넣습니다. 실제 행동에 맞게 각 단계의 문구·시작·종료·위치를 바꿉니다.
- **제품 실사용·비교:** **구성 → 제품·조건 표시 틀 넣기**로 좌우 제품명과 비교 조건을 표시합니다. 확인한 숫자는 설명 표시로 추가할 수 있습니다.
- **비포·애프터:** **구성 → 이전·이후 2구간 구성**을 누른 뒤 각 구간의 원본 시작·종료를 지정합니다. 구간 이름이 이전/이후 라벨로 출력됩니다.
- **TOP 3 목록:** **구성 → TOP 3 구간 구성**을 누르고 각 원본 구간·항목명을 지정합니다. ↑↓로 재생 순서를 바꾸면 항목 번호와 대사 자막 시간도 바뀝니다.

구간을 나누는 버튼은 현재 범위를 균등하게 나눈 편집 틀입니다. 실제 사건·행동·제품·전후 장면을 자동으로 인식해 확정하지 않으므로 미리보기에서 직접 확인하세요. 설명 표시는 완성본 시간 기준, 대사 자막은 원본 시간 기준입니다. 구간을 바꾸거나 순서를 바꾸면 수동 설명 표시의 시간도 확인하세요. 구간별 이름 표시는 자동으로 따라갑니다.

연결 편집에서는 자동 구간 추천이 꺼지며, **구성**에서 각 구간의 화면·크롭을 조정합니다. 기존 버전의 사용자 프리셋 JSON도 가져올 수 있습니다.
