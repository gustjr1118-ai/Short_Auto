Windows x64용 Shorts Studio bySom입니다. `.7z` 압축을 모두 푼 뒤 같은 폴더에 있는 `Shorts Studio bySom.exe`를 실행하세요.

- 원본 전체에서 하이라이트를 추천하고 구간을 편별로 확인·확정합니다.

- 작업 현황과 Codex 잔여량·토큰 사용량을 앱에서 확인합니다.
