# MVP 0.3 검증 기록

검증일 2026-11-20

- 단위·작업 테스트 38개, TypeScript, Vite, Windows x64 패키징을 통과했다.
- 격리된 설정에서 Windows 0.3.0을 실행해 Codex 모델을 입력하고 중간 추론 강도를 선택했다. 저장 후 설정을 다시 열어 두 값을 확인했다.
- Codex 응답을 대신한 테스트로 모델·추론 인수, 구조화 출력 요청, 범위 밖·중복 후보 제외, 원본 자막 시간 유지와 예시 제외를 확인했다.
- 실제 FFmpeg로 15초 MP4 두 편의 일괄 제작, 시간 지정 블러·박스, 크롭, 연결 구간 SRT 시간, 테스트 음성의 원음 혼합·교체를 확인했다. 이전 연결 구간 출력 4건도 재검증했다.
- 공식 Windows whisper.cpp b5127과 다국어 tiny 양자화 모델로 공개 영어 샘플을 실제 전사했다. 한글 파일명 사용, SRT 시각, 캐시 재사용을 확인했다.
- 배포 ZIP 84개 항목 무결성과 패키지 내부 실행 모듈 14개가 작업 파일과 일치함을 확인했다.
- Codex 실제 계정, 유튜브 CC 가져오기, 한국어 전사 품질 및 실제 Qwen3-TTS 모델 실행은 별도 검증 대상이다.
- 이 버전의 원본 한도는 30분·2GB이다. 더 큰 원본·별도 요약 내레이션 트랙·드래그 편집·여러 마스크·배치 ZIP 저장은 단계적으로 진행한다.

### 범위와 제한

- 단계·제품·전후·항목 구간은 사용자가 지정하고 문구를 확인한다. 실제 화면을 자동으로 이해해 사건·수치를 확정하는 기능은 구현하지 않았다.
- 대사 자막은 원본 시간, 일반 설명 표시는 완성본 시간이다. 연결 순서 변경 시 일반 설명 시간은 수동 확인이 필요하며 구간 이름·대사 자막은 자동 재배치한다.
- 편집 미리보기는 배치 예시다. 최종 폰트·배경·오디오 믹싱은 완성 MP4가 기준이다. 원본 미리보기 재생 조작을 영상 밖으로 옮겨 자막과 겹치지 않게 했다.
- 첫 8종 렌더 중 한 번 미디어 도구가 진단 출력 없이 종료했다. 같은 입력 전체 재실행은 8종 모두 통과했으며 추가 4개 연결 사례도 통과했다. 도구 오류에는 종료 코드를 남기도록 개선했다.
- 실제 사용자 API·CLI 계정 호출·다른 PC/DPI·장시간/가변 프레임률 코덱 검수는 이번 추가 검증 범위에 포함하지 않았다.

## 실행한 검사

```text
node --test tests/domain.test.cjs tests/store-jobs.test.cjs tests/worker.test.cjs
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
node scripts/render-smoke.cjs
node scripts/package.cjs dir
```

`render-smoke.cjs`의 상세 결과는 `.smoke-data/한글 경로/verification.json`에 기록한다. 생성한 영상은 각 프리셋의 `renders/<ID>/final.mp4`에 있다. 공개 유튜브 원본의 렌더 결과는 `.smoke-data/youtube-render/renders/`에 있다.

## 사용한 도구

- Electron 45.4.1
- FFmpeg / FFprobe 9.0.2 Gyan essentials build
- yt-dlp 2026.10.26
- React 19.3.0, Vite 8.3.4, TypeScript, SQL.js

FFmpeg와 yt-dlp 실행 파일은 공식 출처에서 받고 배포 체크섬과 대조했다. `assets/tools/versions.json`에는 바이너리 SHA256을 기록한다.

## 수정하고 다시 확인한 문제

- FFmpeg 9에서 제거된 `-filter_complex_script` 대신 인자 배열의 `-filter_complex`를 사용했다. 세 프리셋과 실제 링크 원본 모두 다시 렌더링했다.
- Electron에서 지원하지 않는 `window.prompt()`를 앱 내부 이름 입력 대화상자로 바꿨다.
- 작업 취소 뒤 늦게 도착한 성공 결과는 완성본에 등록하지 않도록 검사했다.
- 앱 종료 시 진행 중 작업은 취소 신호를 처리할 시간을 준 뒤 종료하도록 구성했다.
- 실패는 완료로 대체하지 않는다. 전사 키 누락, 잘못된 AI 응답, 영상 도구 오류는 실패 상태로 전달한다.

## 남은 검증과 제한

- 자동 전사와 Codex/Claude의 실제 계정 호출은 사용자가 연결한 환경에서 확인해야 한다. Codex 실행 옵션은 이 PC에 설치된 CLI의 `exec --help`에서 확인했다.
- BGM 믹싱·다양한 코덱·가변 프레임률·회전 영상·30분 원본 전체의 대표 샘플 검수는 추가 검증 대상이다.
- 유튜브 첫 테스트 ID는 접근 불가 오류를 반환했다. 다른 공개 영상에서는 확보와 렌더링에 성공했다. 모든 링크의 접근 가능성을 보장하지 않는다.
- GUI 재생 버튼과 MP4 저장 대화상자 확정, 모든 프리셋 편집 항목의 GUI 조작, 다른 PC·DPI 배율은 이번 검증에 포함하지 않았다.
- 영상 프리뷰는 배치 예시이며 최종 글꼴·배경·시간은 렌더링된 MP4가 기준이다.
- 생성형 영상·복제 음성·다중 구간 편집·자동 얼굴 추적·SNS 게시·편집기 프로젝트 출력은 v0.1 범위에 없다.
